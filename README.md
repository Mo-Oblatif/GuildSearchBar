# Guild Search Bar

Find any guild member in a second. Guild Search Bar adds a search bar at the top left of the guild roster (Guild & Communities window, roster view).

## Features

- Type part of a name and the roster shows only the matching members, online members first. Clear the bar to get the full roster back.
- Results look exactly like the roster: same rows, same columns, same colours.
- Right-click a result to open the usual guild member menu, the same one as in the roster.
- Accents and case don't matter: "eleo" finds "Éléonore".
- Also searches public and officer notes (handy to find a main from an alt). Turn it off with `/gsb notes`.
- Alt + drag the search bar to move it if it overlaps something in your layout. `/gsb reset` puts it back.

## Commands

- `/gsb` – help
- `/gsb notes` – also search in notes (on by default)
- `/gsb reset` – reset the search bar position

## Safe by design

The addon never modifies Blizzard's roster list: while you search, it only hides it and shows its own copy in the same place. Guild actions from the normal roster keep working.

Languages: English, French.

# Guild Search Bar (FR)

Trouve n'importe quel membre de ta guilde en une seconde. Guild Search Bar ajoute une barre de recherche en haut à gauche de la liste des membres (fenêtre Guilde et communautés, vue Liste).

- Tape une partie du nom : la liste n'affiche plus que les membres correspondants, ceux en ligne d'abord. Vide la barre pour retrouver toute la liste.
- Les résultats ont exactement le même visuel que la liste des membres.
- Clic droit sur un résultat : le menu habituel du membre, le même que dans la liste.
- Les accents et les majuscules ne comptent pas.
- Cherche aussi dans les notes publiques et d'officier (pratique pour retrouver le main d'un reroll). Désactivable avec `/gsb notes`.
- Alt + glisser pour déplacer la barre, `/gsb reset` pour la remettre en place.
